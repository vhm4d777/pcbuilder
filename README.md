## Что это

PC Builder AI помогает подобрать комплектующие для компьютера. Укажите бюджет и задачу, опишите ПК
своими словами, и сайт соберёт сборку из 8 совместимых деталей. Любую деталь можно заменить, и цена
сразу пересчитается.

1. Опишите, какой ПК вам нужен.
2. Сайт подбирает 8 комплектующих.
3. Сайт проверяет совместимость.
4. Меняйте детали, цена пересчитывается.

## Возможности

| Раздел | Что внутри |
|---|---|
| **Конфигуратор** | Бюджет, страна, город и валюта, задача (игры, стриминг, работа, программирование, монтаж, 3D, ИИ). Подбор процессора, видеокарты, памяти, накопителя, материнской платы, блока питания, корпуса и охлаждения с проверкой совместимости и пояснением, почему выбраны именно эти детали |
| **3D-модель** | Объёмная модель собранного ПК, которую можно вращать |
| **Готовые ПК** | Подборка готовых компьютеров |
| **Ноутбуки** | Подборка ноутбуков |
| **Гарнитуры и периферия** | Наушники, мыши, клавиатуры, коврики |
| **Б/у** | Поиск подержанных комплектующих, ноутбуков и периферии. Кнопки открывают поиск на площадках вашей страны |

Ещё:

- **50 языков интерфейса**, в том числе русский, английский, турецкий и украинский;
- светлая и тёмная тема (подстраивается под систему);
- адаптивная вёрстка для телефона и компьютера.

> [!NOTE]
> Сайт ничего не продаёт: цены ориентировочные, а кнопки ведут на поиск в магазинах и на площадках.

## ИИ-функции

Подбор по описанию «своими словами», текстовые пояснения к сборке и оценку б/у деталей делает Claude.
Эти функции работают, когда сайт открыт как артефакт в [claude.ai](https://claude.ai).

На GitHub Pages ИИ недоступен, и сайт работает без него. Сборку подбирает встроенный алгоритм по
бюджету и задаче, а описание разбирается по ключевым словам («белый», «тихий», «компактный», «NVIDIA»,
«32 ГБ» и т. п.). Совместимость проверяется так же, все разделы работают.

## Запуск

Сайт состоит из одного файла [`index.html`](index.html): без сборки, без зависимостей и без сервера.

- **Онлайн:** https://vhm4d777.github.io/pcbuilder/
- **Локально:** скачайте `index.html` и откройте его в браузере.

Шрифты (Unbounded, Onest) загружаются из Google Fonts, поэтому без интернета вид будет немного другим.

## Публикация

Сайт раздаётся через **GitHub Pages** из ветки `main`. Чтобы обновить сайт, закоммитьте изменённый
`index.html` и отправьте его в `main`: через минуту-две новая версия появится по ссылке выше.

```bash
git add index.html
git commit -m "Обновление сайта"
git push
```
